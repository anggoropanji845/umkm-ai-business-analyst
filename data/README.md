# Dataset

This project uses the **Indonesia E-Commerce Sales** dataset obtained from Kaggle.

## Data Source
- Platform: Kaggle
- Dataset: Indonesia E-Commerce Sales
- Source URL: [https://www.kaggle.com/datasets/zkyfauzi/indonesia-ecommerce-sales]

## Data Processing
The original dataset was processed using Python and Pandas in Google Colab.

The preprocessing workflow includes:
- Data inspection
- Missing value handling
- Data cleaning
- Data preparation for business analysis

The cleaned dataset is subsequently used in the Langflow AI workflow.

**Note:** The dataset is not included in this repository. Please download it from the original Kaggle source.
