# Data Dictionary | Kamus Data

## Bahasa Indonesia

Dokumen ini menjelaskan beberapa kolom terpilih yang digunakan dalam analisis transaksi e-commerce.

| Nama Kolom | Deskripsi |
|---|---|
| order_date | Tanggal pesanan |
| Status Pesanan | Status pesanan |
| Provinsi | Provinsi pelanggan |
| total_qty | Total kuantitas produk per pesanan |
| Metode Pembayaran | Metode pembayaran yang digunakan |

Catatan: Daftar ini hanya mencakup beberapa kolom terpilih. Untuk struktur data lengkap, silakan merujuk pada dataset asli di Kaggle.

## English

This document describes selected fields used in the e-commerce transaction analysis.

| Column Name | Description |
|---|---|
| order_date | Order date |
| Status Pesanan | Order status |
| Provinsi | Customer province |
| total_qty | Total product quantity per order |
| Metode Pembayaran | Payment method used |

Note: This is a selected overview of the dataset fields. Refer to the original Kaggle dataset for the complete schema.
