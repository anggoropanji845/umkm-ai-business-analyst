# Project Limitations | Keterbatasan Proyek

## Bahasa Indonesia

### Keterbatasan Data
Versi proyek saat ini berfokus pada analisis performa transaksi. Terdapat beberapa keterbatasan data yang perlu diperhatikan:

1. Dataset tidak menyediakan informasi Harga Pokok Penjualan (HPP).
2. Biaya komisi dan administrasi marketplace aktual tidak tersedia.
3. Pengeluaran iklan tidak termasuk dalam dataset.
4. Biaya pengembangan, hosting, dan pemeliharaan website tidak tersedia.
5. Biaya akuisisi pelanggan untuk website independen tidak tersedia.

### Dampak terhadap Analisis
Sistem saat ini belum dapat menghitung laba bersih aktual atau menentukan secara meyakinkan apakah suatu penjual telah layak secara finansial untuk beralih dari marketplace ke website independen.

### Pengembangan Selanjutnya
- Input profil keuangan penjual.
- Perbandingan biaya marketplace dan website independen.
- Analisis kelayakan strategi multichannel.
- Simulasi skenario keuangan.

## English

### Data Limitations
The current version focuses on transaction performance analysis. Several data limitations should be considered:

1. The dataset does not provide Cost of Goods Sold (COGS).
2. Actual marketplace commission and administrative fees are unavailable.
3. Advertising expenditure is not included.
4. Website development, hosting, and maintenance costs are unavailable.
5. Customer acquisition costs for independent websites are not provided.

### Impact on Analysis
The current system cannot calculate actual net profit or conclusively determine whether a seller is financially ready to transition from a marketplace to an independent website.

### Future Development
- Seller financial profile input.
- Marketplace versus independent website cost comparison.
- Multichannel strategy feasibility analysis.
- Financial scenario simulation.
